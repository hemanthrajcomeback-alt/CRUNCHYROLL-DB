# Crunchyroll Downloader Telegram Bot

This is a Telegram bot that can download videos from Crunchyroll.

## Features

- List episodes from a Crunchyroll series URL
- Select video quality
- Download and upload videos to Telegram

## Deployment

This bot is ready to be deployed on Render.

## Usage

1. `/start` - Welcome message
2. `/series <series_url>` - Lists episodes
3. Click an episode - Choose quality - Bot downloads & sends to Telegram
